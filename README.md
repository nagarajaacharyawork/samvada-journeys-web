# Samvada Journeys

India's first entrepreneur-led experiential travel company. Curated journeys that connect you with hidden places, local communities, food, and authentic culture.

## Tech Stack

- [TanStack Start](https://tanstack.com/start) — Full-stack React framework
- [React](https://react.dev/) — UI library
- [TypeScript](https://www.typescriptlang.org/) — Type safety
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS

## Development

### Prerequisites

- Node.js 18+ — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Getting Started

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

### Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |
| `npm run format` | Format code with Prettier |

## Deployment

This project is configured for deployment on [Vercel](https://vercel.com). Push to the connected branch and Vercel will automatically build and deploy.
